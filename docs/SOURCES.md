# Source register

Every factual claim about a third-party platform in [`ARCHITECTURE_DECISION_LOG.md`](./ARCHITECTURE_DECISION_LOG.md) cites one of these sources by ID, and repeats its URL. Evidence write-ups with file:line citations are in [`adr/evidence/`](./adr/evidence/).

**Authority levels:**
1. Official Meta SDK, docs, reference samples, policies and specifications.
2. Official S-Bank / S Group challenge and product documentation.
3. Official repositories, API documentation and licence files.
4. Peer-reviewed research and standards.
5. Independent open-source repositories with inspectable code.
6. Reputable reporting and practitioner analysis.
7. Unverified posts. These may raise questions, but cannot alone justify an architectural claim.

**Pinned commits.** Repositories are recorded at the commit that was read. Re-check them when you upgrade the SDK or reuse a pattern.

## Known gaps in the evidence base

- **Challenge documentation is partial.** The official dataset is now registered (S22), so the dataset questions are settled: it has balances, salary dates, categories and merchant codes, and no receipts or S Group basket data. The challenge brief and judging criteria are still missing. Several finance assumptions in [`finance/REFERENCE_DESIGN.md`](./finance/REFERENCE_DESIGN.md) remain unverified until they are found. **Action:** add the brief as S24 when it is available.
- **FYN (S17) is unresolved.** No decision depends on it. The consent and scope patterns rely on S13–S15.
- **Ray-Ban Meta (non-Display) input inventory.** Which glasses inputs DAT exposes on the team's exact device is unverified until hour 0 on real hardware (S04 says availability varies by device).
